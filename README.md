# ⚡ Volt

A decentralized NFT marketplace inspired by modern digital collectible platforms. **Volt** allows users to connect their crypto wallet, explore NFT collections, mint digital assets, and experience a clean marketplace interface built with React.

## Features

* 🔐 MetaMask wallet connection
* 🖼️ Mint and display NFT collectibles
* 🛒 Browse featured NFT collections
* 📄 NFT detail pages with metadata
* 📱 Fully responsive user interface
* ⚛️ Component-based React architecture

## Tech Stack

* **Frontend:** React, JavaScript, CSS
* **Blockchain:** Ethereum
* **Wallet:** MetaMask
* **Development:** Node.js, npm

## Getting Started

```bash
git clone https://github.com/your-username/Volt.git
cd Volt
npm install
npm start
```
